# Workspace restoration

## Language

**Source position (A)**:
The fixed, marked starting location where the operator places the object in a consistent orientation before each run.

**Destination position (B)**:
The fixed, marked location to which the object is moved for the first milestone.

**Side wall**:
The nearby wall beside the gripper, identified by the user as the contacted surface.

**Front wall**:
The separate wall on the right of the current 3D view, approximately 40 cm from the base axis according to the user. This supersedes the earlier ambiguous use of “front wall” for the contacted surface.


**Workshop block**: The carton approved as the tutorial's pickup object.

**Workshop receiving target**: Marker B, approved instead of a bin. The carton
is set down on the tabletop before release.
